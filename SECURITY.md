# Security Policy

**This policy covers PromptSploit only. It is not the policy of Promptfoo Inc. or OpenAI.** For vulnerabilities in upstream promptfoo, report to [promptfoo/promptfoo](https://github.com/promptfoo/promptfoo/security) instead.

## Scope and status

PromptSploit is an early-stage solo project and is not production-ready. It should not be relied on for security-critical work at this time.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository:

**[Report a vulnerability](https://github.com/QuantumBitX/promptsploit/security/advisories/new)**

Please do not open a public issue for security problems.

Include where possible: affected version or commit, a description of the issue, reproduction steps, and impact.

As a solo project there is no formal SLA. Reports will be acknowledged as soon as practical.

## A note on intended use

PromptSploit is red teaming and vulnerability scanning tooling for AI systems. It is intended for testing systems you own or are explicitly authorised to test. Findings it produces describe weaknesses in systems under test; that is the tool working as designed, not a vulnerability in PromptSploit.
